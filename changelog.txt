## [v1.0.2] - 2026-09-28

### Added
- Chrome support: the extension now builds and runs as a Chrome Manifest V3 extension (Chrome 127+).

### Fixed
- Context-menu actions and region scanning no longer lose their state when the browser suspends the background script.
- Region scanning decodes in the scan overlay, so the first scan after the background wakes up is faster.
- Portuguese translation now uses the pt_BR locale code, so Chrome recognizes it.

## [v1.0.1] - 2026-09-23

### Changed
- Renamed the extension to ZenQR, with a new add-on ID (zenqr@zenloading).
- Project links now point to https://github.com/zenLoading/ZenQR.

## [v1.0.0] - 2026-09-12

### Added
- Initial release of ZenQR.
- Generate QR codes for the current tab, selected text/links, or free-form input, with adjustable error correction level, image size, finder/module styles, and an optional embedded logo.
- Build QR codes from templates: WiFi network, contact card (vCard), email, SMS, phone number, and calendar event.
- Batch-generate QR codes from multiple lines of text at once.
- Scan QR codes from images, a selected screen region, or the camera.
- Track generation/scan history, with import/export to a JSON file.
- Works offline, with no accounts, analytics, or third-party services. Nothing you generate or scan is sent anywhere.
