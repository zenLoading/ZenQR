Make a QR code, right in your browser.

ZenQR generates and scans QR codes without a server in between. Nothing you type, paste, or scan ever leaves your device — not even to make the code you're looking at right now.

One popup, four ways to make a code.

Paste something and get a QR code back — or reach for a template, a batch, or a logo when you need more than that.

Type, paste, or right-click

Generate a code for the current tab, a selected link, or anything you type. Adjust the error correction level, image size, and the shape of the finder patterns and modules as you go.

Fill in a form, not a spec

WiFi logins, contact cards, calendar invites, emails, and phone numbers each have their own encoding. Templates fill it in correctly, so you don't have to look it up.

One at a time is slow

Paste a list of links and get a QR code for every line at once, ready to save individually or all together.

Put your mark on it

Drop in an image and ZenQR centers it in the code, sized and backed so the code still scans reliably.

Nothing you generate or scan ever leaves this device.

No account, no upload, no analytics. Here's what actually runs where.

Generate

Codes are built by an on-device encoder. There's no API call and no generation server — ZenQR works with your network disconnected.

Scan

Images, screen regions, and camera frames are decoded on-device with a bundled computer-vision model, not a cloud vision API.

Store

History and settings live in your browser's own local storage. Export it to a file whenever you want a copy, or turn it off entirely.

Get it

ZenQR isn't on an extension store yet. Clone the repo and build it — it takes about a minute.

# clone and build
git clone https://github.com/zenLoading/ZenQR.git
cd ZenQR
yarn install && yarn build

Then load dist/chrome or dist/firefox as an unpacked extension in your browser.
